# ML Deep Learning Studio

機械学習・深層学習を段階的に学ぶためのブラウザアプリです。教材、ミニ実験、クイズ、進捗管理を 1 つの画面で扱えます。

## 使い方

`index.html` をブラウザで開くだけで動きます。追加のインストールは不要です。

## 主な機能

- 学習ロードマップ
- E資格対策を意識した重要用語カード
- 用語ごとの Python コードサンプル
- 用語カードから開ける詳細ページ
- 選択問題と Python コード穴埋め問題
- カテゴリ・問題番号から直接選べる問題ブラウザ
- ヒストグラム・散布図・箱ひげ図を使った統計グラフ読解問題
- 回答後の詳しい解説
- 入力、処理、出力結果まで確認できるコード実行例
- 欠損値処理、標準化、カテゴリ変数、データリークなどの前処理教材
- 転移学習、Mixed Precision、知識蒸留、データ拡張などの発展技術
- Python、NumPy、Pandas、統計、確率分布、最適化、CNN、系列モデル、Transformer、生成モデル、GNN、評価指標を横断
- 教師あり・教師なし・半教師あり・自己教師あり・強化学習を整理
- 線形/ロジスティック回帰、SVM、決定木、Random Forest、k-NN、Naive Bayes、Gradient Boostingを収録
- k-means、PCA、NumPy/Pandas実践操作、追加の確率分布を収録
- `np.c_`、`np.r_`、`newaxis`、`einsum`、Pandasの高度な選択・変換を収録
- Pooling、Dilated/Transposed Convolution、ResNet Bottleneck、BPTT、Bidirectional RNN、Seq2Seqを収録
- Graph Transformer、R-GCN、異種グラフ、Graph Contrastive Learning、Over-squashing、Graph Positional Encodingを収録
- Truncated BPTT、Peephole LSTM、ConvLSTM、Scheduled Sampling、CTC Lossなど系列モデルの応用を収録
- Graph Mini-batch Sampling、Ablation Study、Calibrationなど研究・論文実装で役立つ観点を収録
- 学習率とエポックを変えられるミニ実験
- ローカル保存される進捗チェック

## GitHub Pages

GitHub Pages で公開する場合は、リポジトリの Settings から Pages を開き、`develop` または公開用ブランチのルートを指定してください。
