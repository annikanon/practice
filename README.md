# ML Deep Learning Studio

機械学習・深層学習を段階的に学ぶためのブラウザアプリです。教材、ミニ実験、クイズ、進捗管理を 1 つの画面で扱えます。

## 使い方

`index.html` をブラウザで開くだけで動きます。追加のインストールは不要です。

## 主な機能

- 学習ロードマップ
- E資格対策を意識した重要用語カード
- 用語ごとの Python コードサンプル
- 用語カードから開ける詳細ページ
- 選択問題と Python コード穴埋め問題
- 回答後の詳しい解説
- 数学、最適化、正規化、正則化、CNN、系列モデル、Transformer、生成モデル、評価指標を横断
- 学習率とエポックを変えられるミニ実験
- ローカル保存される進捗チェック

## GitHub Pages

GitHub Pages で公開する場合は、リポジトリの Settings から Pages を開き、`develop` または公開用ブランチのルートを指定してください。
